# congenial-octo-pancake

A simple, responsive calculator built with HTML, CSS, and vanilla JavaScript. No dependencies or build tools are required.

## Run the calculator

Open `index.html` in any modern web browser.

## Features

- Addition, subtraction, multiplication, and division
- Decimal numbers and sign toggle
- Clear and delete controls
- Keyboard support: number keys, `+`, `-`, `*`, `/`, `.`, `Enter`, `Backspace`, and `Escape`
- Responsive layout with accessible button labels

## Project files

- `index.html` — calculator markup, styles, and JavaScript logic
